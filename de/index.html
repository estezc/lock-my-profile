Kostenlose Browser-Erweiterung

Sperren Sie Ihren Browser mit einem Passwort

Lock My Profile schützt Ihr Chrome-Profil und ausgewählte Websites mit einem Passwort und kann einen gesperrten Tab als harmlose Seite tarnen. Ohne Konto. Nichts verlässt Ihr Gerät.

Alles, was Ihren Browser privat hält

Für gemeinsam genutzte Computer, das Büro oder alle, die sich an Ihren Platz setzen, während Sie weg sind.

Ganzes Profil sperren

Alle offenen Tabs verschwinden hinter einem Sperrbildschirm, bis Sie Ihr Passwort eingeben. Sofort sperren mit Strg+Umschalt+L.

Nur einzelne Websites schützen

E-Mail, Chats oder Online-Banking fragen nach dem Passwort, auch wenn der Browser entsperrt ist.

Automatische Sperre

Nach ein paar Minuten Inaktivität, beim Start von Chrome, bei gesperrtem Computer oder minimiertem Fenster.

Getarnte Tabs

Ein gesperrter Tab kann wie eine andere Website aussehen oder gegen eine echte, harmlose Seite getauscht werden.

Einbruchsprotokoll

Jedes falsche Passwort wird mit Datum und Uhrzeit festgehalten. Export als CSV möglich.

Schutz vor Brute-Force

Nach 5 Fehlversuchen (einstellbar) folgt eine Zeitsperre, die sich jedes Mal verdoppelt, bis zu 15 Minuten.

Getarnte Tabs

Kurz weg? Andere sehen nur Wikipedia.

Verlassen Sie einen geschützten Tab, wird er gegen eine harmlose Seite getauscht: Die Adressleiste zeigt die echte Adresse dieser Website. Ihr eigener Tab wartet unverändert in einem minimierten Fenster, und eine kleine Passwortleiste auf der Seite holt ihn zurück.

  • Seite wählen: Wikipedia, YouTube, Google, Nachrichten und mehr
  • Oder den Tab behalten und nur Titel und Symbol tarnen
  • Strg+Umschalt+U holt den echten Tab zurück
Geschützte Websites

Nur sperren, was wichtig ist

Fügen Sie die Websites hinzu, die privat bleiben sollen. Sie fragen bei jedem Öffnen nach dem Passwort, während der Rest des Browsers frei nutzbar bleibt.

  • Inklusive Subdomains
  • Bleibt so lange offen, wie Sie wählen: 5 Minuten bis 4 Stunden
  • Sperrt sich wieder, sobald Sie den Tab wechseln
Einbruchsprotokoll

Sehen, wer es versucht hat

Lock My Profile protokolliert jedes Sperren, Entsperren und jeden Fehlversuch. So wissen Sie, ob jemand Ihren Browser öffnen wollte, während Sie weg waren.

  • Datum und Uhrzeit jedes Versuchs
  • Export als CSV
  • Sicherheitswert mit Tipps für einen stärkeren Schutz

Privat von Grund auf

Ihr Passwort und Ihre Aktivität bleiben auf Ihrem Gerät. Immer.

Kein Konto, keine Server

Keine Registrierung, keine Datenübertragung. Keine Analyse, keine Werbung, kein Tracking.

Ihr Passwort wird nie gespeichert

Gespeichert wird nur ein gesalzener PBKDF2-SHA256-Hash (210.000 Iterationen) im lokalen Speicher Ihres Browsers.

Ehrlich zu den Grenzen

Die Erweiterung schützt Ihren Browser vor Menschen, die Ihren Computer benutzen. Für vollen Schutz nutzen Sie zusätzlich das Passwort Ihres Benutzerkontos.

Häufige Fragen

Ist Lock My Profile kostenlos?

Ja. Sie können die Erweiterung kostenlos installieren und alle Funktionen nutzen.

Werden meine Daten irgendwohin gesendet?

Nein. Es gibt weder Server noch Konto. Ihre Einstellungen, der Hash Ihres Passworts und das Aktivitätsprotokoll bleiben im lokalen Speicher Ihres Browsers.

Kann man die Erweiterung einfach deaktivieren?

Solange das Profil gesperrt ist, blockiert Lock My Profile die internen Seiten von Chrome, auch die Erweiterungsseite. Dort lässt sie sich also nicht abschalten. Sie soll Menschen aufhalten, die Ihren Computer benutzen; wer volle Kontrolle über den Computer hat, könnte sie dennoch entfernen. Kombinieren Sie sie für maximale Sicherheit mit dem Passwort Ihres Benutzerkontos.

Was, wenn ich mein Passwort vergesse?

Nutzen Sie den Hinweis oder die Sicherheitsfrage auf dem Sperrbildschirm. Haben Sie beides nicht eingerichtet, entfernen Sie die Erweiterung und installieren Sie sie neu: Dabei werden ihre Daten gelöscht und Sie können neu beginnen.

Funktioniert sie auch im Inkognitomodus?

Ja, wenn Sie es erlauben: Öffnen Sie unter chrome://extensions die Details von Lock My Profile und aktivieren Sie „Im Inkognitomodus zulassen“.

Für welche Sprachen und Computer ist sie verfügbar?

Google Chrome unter Windows, macOS, Linux und ChromeOS, auf Deutsch, Englisch, Spanisch, Französisch, Italienisch und Portugiesisch.
