Chrome-Profil mit Passwort schützen

Aktualisiert: 10. November 2026

Kurz gesagt: Chrome-Profile haben kein Passwort. Sie können aber eines hinzufügen, indem Sie Lock My Profile im Profil installieren, das Sie schützen möchten, und die Sperre beim Start von Chrome aktivieren.

Was ein Chrome-Profil ist (und warum es kein Passwort hat)

Ein Profil ist ein eigener Satz aus Lesezeichen, Verlauf, Passwörtern, offenen Tabs und Erweiterungen. Wer den Computer benutzt, kann über das Profilsymbol zu jedem Profil wechseln, denn Chrome versteht Profile als Komfortfunktion, nicht als Sicherheitsmaßnahme.

So sperren Sie ein Profil

Erweiterungen werden pro Profil installiert. Deshalb lässt sich ganz einfach nur das Profil sperren, auf das es Ihnen ankommt:

  1. Öffnen Sie Chrome mit dem Profil, das Sie schützen möchten.
  2. Installieren Sie Lock My Profile in diesem Profil und erstellen Sie Ihr Passwort.
  3. Aktivieren Sie unter Automatisierung die Option Beim Start von Chrome und wählen Sie eine Zeit für Bei Inaktivität sperren.
  4. Lassen Sie unter Sicherheit die Option Interne Seiten blockieren aktiviert, damit sich die Erweiterung bei gesperrtem Profil nicht über die Erweiterungsseite abschalten lässt.
  5. Für weitere Profile wiederholen Sie die Schritte im jeweiligen Profil. Jedes Profil kann ein eigenes Passwort haben.

Was geschützt ist – und wo die Grenzen liegen

Ist das Profil gesperrt, liegen seine Tabs, der Verlauf, gespeicherte Sitzungen und die Websites, bei denen Sie angemeldet sind, hinter dem Sperrbildschirm. Beachten Sie:

  • Jemand könnte trotzdem ein Fenster im Gastmodus öffnen oder ein neues Profil anlegen. Dort sieht er keine Ihrer Daten, kann aber surfen.
  • Wenn Sie auch das verhindern möchten, geben Sie jeder Person ein eigenes Benutzerkonto auf dem Computer. Auf Computern, die von einem Unternehmen oder einer Schule verwaltet werden, können Administratoren den Gastmodus und das Hinzufügen von Profilen per Chrome-Richtlinien abschalten.
  • Eine Sperr-Erweiterung schützt vor Menschen, die Ihren Computer benutzen. Sie ersetzt weder das Passwort Ihres Benutzerkontos noch die Festplattenverschlüsselung.

Oder nur einzelne Websites sperren

Wenn Sie nicht das ganze Profil sperren möchten, schützen Sie nur einzelne Websites, etwa Ihr E-Mail-Postfach oder WhatsApp Web. Sie fragen nach dem Passwort, während der Rest des Profils normal funktioniert.
