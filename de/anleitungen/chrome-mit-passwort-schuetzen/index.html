Chrome mit Passwort schützen: So geht’s

Aktualisiert: 10. November 2026

Kurz gesagt: Chrome fragt beim Start nach keinem Passwort. Am schnellsten richten Sie eines mit einer Sperr-Erweiterung wie Lock My Profile ein; am sichersten ist ein eigenes Benutzerkonto auf dem Computer für jede Person. Viele nutzen beides.

Hat Chrome eine Passwort-Option?

Nicht für das Öffnen des Browsers. In Chrome können Sie mehrere Profile anlegen und sich mit einem Google-Konto anmelden, aber beides verlangt kein Passwort, wenn jemand Chrome auf Ihrem Computer öffnet. Auch das Abmelden vom Google-Konto hilft nicht: Offene Tabs, Verlauf und Websites, bei denen Sie noch angemeldet sind, bleiben auf dem Computer.

Weg 1: ein eigenes Benutzerkonto auf dem Computer

Teilen sich mehrere Personen einen Computer, ist ein eigenes Konto im Betriebssystem für jede Person die sicherste Lösung. Chrome hält die Daten jedes Kontos getrennt, und ohne das Computer-Passwort kann niemand Ihres öffnen.

  • Windows: Einstellungen › Konten › Andere Benutzer › Konto hinzufügen.
  • macOS: Systemeinstellungen › Benutzer:innen & Gruppen › Benutzer:in hinzufügen.

Der Nachteil: Alle müssen das Konto wechseln, und es hilft nicht, wenn jemand den Computer benutzt, während Sie noch angemeldet sind.

Weg 2: eine Sperr-Erweiterung (am schnellsten)

Eine Sperr-Erweiterung legt einen Passwort-Bildschirm vor Chrome. So geht es mit Lock My Profile, das kostenlos ist und alles auf Ihrem Gerät speichert:

  1. Installieren Sie Lock My Profile aus dem Chrome Web Store und klicken Sie auf das Symbol in der Symbolleiste.
  2. Erstellen Sie Ihr Passwort. Legen Sie einen Hinweis oder eine Sicherheitsfrage fest, falls Sie es vergessen.
  3. Klicken Sie auf Jetzt sperren oder drücken Sie Strg+Umschalt+L. Alle Tabs bleiben verdeckt, bis Sie das Passwort eingeben.
  4. Aktivieren Sie unter Automatisierung die Option Beim Start von Chrome, damit bei jedem Öffnen nach dem Passwort gefragt wird, und wählen Sie eine Zeit für Bei Inaktivität sperren.
  5. Lassen Sie unter Sicherheit die Option Interne Seiten blockieren aktiviert, damit niemand die Erweiterung im gesperrten Zustand über die Erweiterungsseite abschalten kann.

Nur bestimmte Websites schützen?

Sie müssen nicht den ganzen Browser sperren. Fügen Sie unter Geschützte Websites die Seiten hinzu, die privat bleiben sollen, etwa Ihr E-Mail-Postfach oder Online-Banking. Sie fragen dann nach dem Passwort, während der Rest von Chrome frei nutzbar bleibt. Ein Beispiel Schritt für Schritt: WhatsApp Web sperren.

Tipps für einen starken Schutz

  • Verwenden Sie ein Passwort, das Sie nirgendwo sonst nutzen.
  • Deaktivieren Sie auf einem gemeinsam genutzten Computer Hinweis auf dem Sperrbildschirm zeigen, damit niemand daraus Ihr Passwort errät.
  • Werfen Sie ab und zu einen Blick ins Protokoll: Es listet jeden Fehlversuch mit Datum und Uhrzeit auf.

Eine Sperr-Erweiterung schützt Ihren Browser vor Menschen, die Ihren Computer benutzen. Sie ersetzt weder das Passwort Ihres Benutzerkontos noch die Festplattenverschlüsselung. Für maximale Sicherheit nutzen Sie beides.
