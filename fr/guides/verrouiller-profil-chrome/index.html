Comment verrouiller un profil Chrome avec un mot de passe

Mise à jour : 10 novembre 2026

En bref : les profils Chrome n’ont pas de mot de passe, mais vous pouvez en ajouter un en installant Lock My Profile dans le profil à protéger et en activant le verrouillage au démarrage de Chrome.

Qu’est-ce qu’un profil Chrome (et pourquoi n’a-t-il pas de mot de passe) ?

Un profil est un ensemble distinct de favoris, d’historique, de mots de passe, d’onglets ouverts et d’extensions. Toute personne qui utilise l’ordinateur peut passer à n’importe quel profil depuis l’icône de profil, car Chrome les conçoit comme une commodité, pas comme une mesure de sécurité.

Comment verrouiller un profil

Les extensions s’installent profil par profil. Il est donc facile de verrouiller uniquement le profil qui compte pour vous :

  1. Ouvrez Chrome avec le profil à protéger.
  2. Installez Lock My Profile dans ce profil et créez votre mot de passe.
  3. Dans Automatisation, activez Au démarrage de Chrome et choisissez un délai pour Verrouiller après inactivité.
  4. Dans Sécurité, laissez Bloquer les pages internes activé : l’extension ne pourra pas être désactivée depuis la page des extensions tant que le profil est verrouillé.
  5. Pour verrouiller d’autres profils, répétez ces étapes dans chacun d’eux. Chaque profil peut avoir son propre mot de passe.

Ce qu’il protège, et ses limites

Quand le profil est verrouillé, ses onglets, son historique, ses sessions enregistrées et les sites où vous êtes connecté sont masqués derrière l’écran de verrouillage. À savoir :

  • Quelqu’un pourrait encore ouvrir une fenêtre Invité ou créer un nouveau profil. Il n’y verra aucune de vos données, mais pourra naviguer.
  • Pour empêcher cela aussi, donnez à chacun son propre compte sur l’ordinateur ; sur les ordinateurs gérés par une entreprise ou un établissement scolaire, un administrateur peut désactiver le mode Invité et l’ajout de profils grâce aux règles Chrome.
  • Une extension de verrouillage protège des personnes qui utilisent votre ordinateur. Elle ne remplace ni le mot de passe de votre compte sur l’ordinateur ni le chiffrement du disque.

Ou verrouillez seulement certains sites

Si vous ne voulez pas verrouiller tout le profil, protégez seulement quelques sites, comme votre messagerie ou WhatsApp Web. Ils demanderont le mot de passe pendant que le reste du profil fonctionne normalement.
