Comment mettre un mot de passe sur Chrome

Mise à jour : 10 novembre 2026

En bref : Chrome ne demande pas de mot de passe à l’ouverture. Le moyen le plus rapide d’en ajouter un est une extension de verrouillage comme Lock My Profile ; le plus sûr, donner à chaque personne son propre compte sur l’ordinateur. Beaucoup utilisent les deux.

Chrome propose-t-il un mot de passe à l’ouverture ?

Non, pas pour ouvrir le navigateur. Chrome permet de créer plusieurs profils et de se connecter avec un compte Google, mais aucun des deux ne demande de mot de passe quand quelqu’un ouvre Chrome sur votre ordinateur. Se déconnecter de son compte Google n’aide pas non plus : vos onglets ouverts, votre historique et les sites où vous êtes encore connecté restent sur l’ordinateur.

Option 1 : un compte à part sur l’ordinateur

Si plusieurs personnes partagent l’ordinateur, le plus sûr est que chacune ait son propre compte dans le système. Chrome sépare les données de chaque compte, et personne ne peut ouvrir le vôtre sans le mot de passe de l’ordinateur.

  • Windows : Paramètres › Comptes › Autres utilisateurs › Ajouter un compte.
  • macOS : Réglages Système › Utilisateurs et groupes › Ajouter un utilisateur.

L’inconvénient : chacun doit changer de compte, et cela ne sert à rien si quelqu’un utilise l’ordinateur alors que votre session est encore ouverte.

Option 2 : une extension de verrouillage (la plus rapide)

Une extension de verrouillage place un écran à mot de passe devant Chrome. Voici comment faire avec Lock My Profile, gratuite et qui garde tout sur votre appareil :

  1. Installez Lock My Profile depuis le Chrome Web Store et cliquez sur son icône dans la barre d’outils.
  2. Créez votre mot de passe. Ajoutez un indice ou une question de récupération en cas d’oubli.
  3. Cliquez sur Verrouiller maintenant ou appuyez sur Ctrl+Maj+L. Tous les onglets sont masqués jusqu’à ce que vous saisissiez le mot de passe.
  4. Dans Automatisation, activez Au démarrage de Chrome pour que le mot de passe soit demandé à chaque ouverture, et choisissez un délai pour Verrouiller après inactivité.
  5. Dans Sécurité, laissez Bloquer les pages internes activé : personne ne pourra désactiver l’extension depuis la page des extensions pendant le verrouillage.

Vous voulez protéger seulement certains sites ?

Inutile de verrouiller tout le navigateur. Dans Sites protégés, ajoutez les sites que vous voulez garder privés, comme votre messagerie ou votre banque : ils demanderont le mot de passe même quand le reste de Chrome est libre d’accès. Pour un exemple pas à pas, voyez comment verrouiller WhatsApp Web.

Conseils pour une configuration solide

  • Choisissez un mot de passe que vous n’utilisez nulle part ailleurs.
  • Sur un ordinateur partagé, désactivez Afficher l’indice sur l’écran de verrouillage, pour que personne ne s’en serve pour deviner.
  • Consultez le Journal de temps en temps : il liste chaque tentative échouée avec la date et l’heure.

Une extension de verrouillage protège votre navigateur des personnes qui utilisent votre ordinateur. Elle ne remplace ni le mot de passe de votre compte sur l’ordinateur ni le chiffrement du disque : pour une sécurité maximale, utilisez les deux.
