Como colocar senha no Chrome

Atualizado em: 10 de novembro de 2026

Resposta rápida: o Chrome não pede senha ao abrir. O jeito mais rápido de colocar uma é usar uma extensão de bloqueio como o Lock My Profile; o mais seguro é cada pessoa ter a própria conta no computador. Muita gente usa os dois.

O Chrome tem opção de senha?

Não para abrir o navegador. O Chrome permite criar vários perfis e fazer login com uma Conta do Google, mas nenhum deles pede senha quando alguém abre o Chrome no seu computador. Sair da Conta do Google também não resolve: suas abas abertas, o histórico e os sites em que você continua conectado ficam no computador.

Opção 1: uma conta separada no computador

Se várias pessoas usam o mesmo computador, o mais seguro é cada uma ter a própria conta no sistema. O Chrome mantém os dados de cada conta separados, e ninguém abre a sua sem a senha do computador.

  • Windows: Configurações › Contas › Outros usuários › Adicionar conta.
  • macOS: Ajustes do Sistema › Usuários e Grupos › Adicionar Usuário.

A desvantagem: todo mundo precisa trocar de conta, e isso não ajuda quando alguém usa o computador enquanto a sua sessão ainda está aberta.

Opção 2: uma extensão de bloqueio (a mais rápida)

Uma extensão de bloqueio coloca uma tela de senha na frente do Chrome. Veja como fazer com o Lock My Profile, que é grátis e guarda tudo no seu dispositivo:

  1. Instale o Lock My Profile pela Chrome Web Store e clique no ícone dele na barra de ferramentas.
  2. Crie sua senha. Adicione uma dica ou uma pergunta de recuperação para o caso de esquecer.
  3. Clique em Bloquear agora ou pressione Ctrl+Shift+L. Todas as abas ficam cobertas até você digitar a senha.
  4. Em Automação, ative Ao iniciar o Chrome para que a senha seja pedida toda vez que o Chrome abrir, e escolha um tempo em Bloquear após inatividade.
  5. Em Segurança, deixe Bloquear páginas internas ativado, para que ninguém consiga desativar a extensão pela página de extensões enquanto ela está bloqueada.

Quer proteger só alguns sites?

Você não precisa bloquear o navegador inteiro. Em Sites protegidos, adicione os sites que quer manter privados, como seu e-mail ou o banco, e eles vão pedir a senha mesmo com o resto do Chrome liberado. Veja como colocar senha no WhatsApp Web para um exemplo passo a passo.

Dicas para uma configuração segura

  • Use uma senha que você não usa em nenhum outro lugar.
  • Num computador compartilhado, desative Mostrar a dica na tela de bloqueio, para que ninguém adivinhe a senha por ela.
  • Confira o Registro de vez em quando: ele lista cada tentativa falha com data e hora.

Uma extensão de bloqueio protege o navegador de quem usa o seu computador. Ela não substitui a senha da sua conta no computador nem a criptografia do disco; para ter o máximo de segurança, use as duas coisas.
